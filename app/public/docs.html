All endpoints are JSON unless noted. Local mode only accepts same-origin requests to a loopback host. In --agent mode every /api call needs the x-pp-token header (or ?token=). focus is a statistics window in ms (0 = all).

Probe semantics: ICMP, TCP and UDP route tracing

GET /api/packettypes lists the available probe types; tcp and udp need the native probe helper (Windows) and a port. With a protocol target the route is traced with the protocol itself, not just with ICMP:

  • Discovery. While the path is unknown, protocol probes run at increasing TTLs (1 … maxHops). The smallest TTL at which the destination itself answers is the protocol path length (finalTtl in every target view): for TCP a completed handshake or an RST, for UDP a datagram reply or the ICMP Port Unreachable that a connected UDP socket surfaces as a connection reset. A middle router's ICMP Time-Exceeded does not count as reaching the destination.
  • Steady state. Once finalTtl is known, protocol probes run only at that TTL; every hop below it keeps being measured with TTL-limited ICMP probes each round.
  • Hop attribution (Windows limitation). User-mode TCP/UDP sockets cannot report which router sent an ICMP Time-Exceeded, so intermediate hop addresses always come from the engine's ICMP probes; the protocol probe proves reachability and carries the destination RTT. The same restriction applies to TCP and UDP alike.
  • Destination state. destState on a target view classifies the last final-TTL protocol probe: open (answered), refused (port closed — the destination is reached), filtered (no answer), unreachable (network/host unreachable), unknown (no probe result yet). An unanswered probe is recorded as packet loss on the destination hop and state filtered; it is never reported as “offline”, and tracing continues.
  • Helper protocol. The engine drives the helper over stdin/stdout. Protocol probes: T|U id host port timeoutMs ttl size → id ok|refused|unreach|timeout|err ip ms. Plain ICMP probes (all targets): id host ttl timeoutMs size → id ok|ttl|timeout|err ip ms. Setting PP_HELPER swaps in another helper executable (a .js file runs under the same node binary) — used by the test suite (tests/).
